# posqarpacypress2026
Repositório base com projeto Cypress atual intalado, configurado e completo.

## Sobre esta branch

`main` é a base do projeto, com testes Cypress escritos diretamente em arquivos `.cy.js`, organizados em login e desafios. Esta branch não usa o preprocessor Cucumber/BDD.

## Extensões do VS Code

### Instaladas neste ambiente

- Cucumber (Gherkin) Full Support (`alexkrechik.cucumberautocomplete`)
- Cypress Snippets (`andrew-codes.cypress-snippets`)
- Cucumber Official (`cucumberopen.cucumber-official`)
- Live Server (`ritwickdey.liveserver`)
- Material Icon Theme (`pkief.material-icon-theme`)
- ES6 Mocha Snippets (`spoonscen.es6-mocha-snippets`)
- VSCode Icons (`vscode-icons-team.vscode-icons`)

Esta lista reflete as extensões instaladas no ambiente em que este README foi atualizado; ela pode variar entre computadores.

### Leitura em voz alta das respostas do Copilot

É possível adicionar leitura em voz alta instalando a extensão `abhishekshr.markdown-tts` pelo Marketplace do VS Code. Ela não está instalada neste ambiente. Pesquise pelo ID da extensão na aba **Extensões** do VS Code para conferir os detalhes e instalá-la.
